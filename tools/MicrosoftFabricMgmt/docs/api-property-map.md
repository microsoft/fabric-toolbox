most want (connection strings, service URIs, OneLake paths, FQDNs, provisioning/state, restore
points). Proposed work: surface each as a flat top-level NoteProperty (e.g.
`properties.sqlEndpointProperties.connectionString` -> `SqlEndpointConnectionString`) during
enrichment, leaving the nested object in place. These are the recommended next targets.
